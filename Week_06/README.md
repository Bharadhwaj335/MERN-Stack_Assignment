# Week 06 — HTML/CSS Assignments

Overview
- Collection of small frontend assignments (pure HTML/CSS) demonstrating layout, styling, and responsive grid practice.

Learning focus
- Build static layouts with semantic HTML.
- Apply CSS for spacing, alignment, typography, and responsiveness.
- Practice grid-based page composition and simple multi-page structure.

Contents
- `Assignment_01` - simple static page.
- `Assignment_02` - two web pages with separate CSS files.
- `Assignment_03` - another standalone HTML/CSS page.
- `Assignment_Grid_01` - grid layout exercise.
- `Assignment_Grid_02` - second grid layout exercise.
