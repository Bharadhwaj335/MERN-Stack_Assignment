# Week 07 — React Hands-on (Phases 01–03)

Overview
- Three small React projects (Vite + React) demonstrating progressive React skills across phases. Each phase is a separate subproject with its own `package.json` and `README.md`.

Learning path
- Phase 01 focuses on component composition and product rendering.
- Phase 02 focuses on task management UI patterns.
- Phase 03 focuses on searching, filtering, and card-based list rendering.

Subprojects
- `react-hands-on-phase-01` — starter project and exercises: [react-hands-on-phase-01](Week_07/react-hands-on-phase-01/README.md#L1)
- `react-hands-on-phase-02` — intermediate exercises: [react-hands-on-phase-02](Week_07/react-hands-on-phase-02/README.md#L1)
- `react-hands-on-phase-03` — advanced exercises: [react-hands-on-phase-03](Week_07/react-hands-on-phase-03/README.md#L1)

Shared tooling
- React 19
- Vite
- Tailwind CSS v4
- ESLint

How to run a phase

```bash
cd Week_07/react-hands-on-phase-01
npm install
npm run dev
```

Notes
- Each phase uses Vite. Use `npm run build` to create a production build and `npm run preview` to preview the production build.
- No Vercel deployment link is documented at the Week 07 root yet.
