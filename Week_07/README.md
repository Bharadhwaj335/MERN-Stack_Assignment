# Week 07 - React Hands-on (Phases 01-03)

Overview
- This folder contains three React practice projects, each in a separate subfolder.
- Every phase has its own `README.md`, `package.json`, and `src` tree.

Folder Tree
```text
Week_07/
├── react-hands-on-phase-01/
│   ├── src/
│   ├── public/
│   ├── package.json
│   └── README.md
├── react-hands-on-phase-02/
│   ├── src/
│   ├── public/
│   ├── package.json
│   └── README.md
└── react-hands-on-phase-03/
	├── src/
	├── public/
	├── package.json
	└── README.md
```

Learning Path
- Phase 01 focuses on component composition and product rendering.
- Phase 02 focuses on task management UI patterns.
- Phase 03 focuses on searching, filtering, and card-based list rendering.

Shared Tooling
- React 19
- Vite
- Tailwind CSS v4
- ESLint

Subproject Notes
- Phase 01: product and products components.
- Phase 02: task form, list, and item components.
- Phase 03: search bar, country list, and country card components.

Run a Phase

```bash
cd Week_07/react-hands-on-phase-01
npm install
npm run dev
```

Use the same commands inside phase 02 or phase 03.
