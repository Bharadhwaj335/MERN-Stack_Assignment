# Week 01 - JavaScript Basics

Overview
- This week covers the core JavaScript building blocks used throughout the rest of the assignment.
- Topics include operators, control flow, arrays, and object manipulation.

- [Array-Operations_Advanced.js](Week_01/Array-Operations_Advanced.js#L1) - more advanced array transformations.
