# Week 05 - HTML and CSS Assignments

Overview
- A set of pure HTML and CSS exercises focused on page structure, styling, image handling, and simple multi-page navigation.

Learning focus
- Build semantic HTML pages.
- Link external stylesheets and organize assets.
- Practice floats, typography, spacing, and layout cleanup.
- Work with simple multi-page site navigation.

Contents
- [Assignment1](Assignment1/index.html) - introductory HTML page.
- [Assignment2](Assignment2/index.html) - HTML page with external CSS and an image.
- [Assignment3](Assignment3/index.html) - restaurant landing page layout.
- [Assignment4](Assignment4/index.html) - product page with floated image and lists.
- [Assignment5](Assignment5/index.html) - float-based text wrap exercise.
- [Assignment6](Assignment6/index.html) - hub page with Bangalore, Chennai, and Hyderabad pages.
